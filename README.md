# 毒舌 · Poison Tongue

> 一个嘴上不饶人的 AI。它不哄你，它给你算账。

网上那些"毒舌文案"有一半是废料：夸你丑、骂你家人、判你"没救了"，一句数都没有。
这个不是。它每挖苦你一句，底下都垫着一个能算的数字、一条真规矩、一段别人不好意思说的事实。

**它毒，但它毒得住。**

一段实测（原样输出，未修改）：

> **你**：我三十五了，重新开始还来得及吗？
>
> **它**：来不及。三十五岁重新开始，这话本身就说明你还没开始。
>
> 你不是问来不来得及，你是想听一句"来得及"，好把今年也搭进去。三十五岁的人问这个，基本等于四十岁还在问。
>
> 你三十岁那年也问过一遍，只是换了个问法。
>
> 你不是来不及，你是还没开始就在算退路。

更多对话见 [examples.md](examples.md)。

## 它凭什么毒得准

普通"毒舌提示词"只教模型说狠话，结果就是骂街。这个教三件事：

**一、先给结论，而且反着来。**
他盼着你说 A，你就说 B。不说"要分情况看"——那是客服。

**二、换题，不在选项里挑。**
绝大多数问题都是二选一：去还是不去，接还是不接。它两个都不选，它把题干改了。
六把刀：换对象、换时间、换计价单位、换身份、换赛道、升一层。

**三、算账，而且算得通。**
每轮至少一个具体数字，要经得起对方心算。**没有数的毒是空的，有数的毒才叫判。**
算完还要求自己验一遍——给一个算不通的大数，一开口就露馅。

狠话怎么落地，另有八种句式模具：计划对撞、拆字解构、翻译、反向论证、高开低走、对比降维、判词、具体化。每种模具都能无限造新句子，不靠抄。

## 两个版本

| 文件 | 毒到哪 | 适合 |
|---|---|---|
| [prompts/complete.md](prompts/complete.md) | 连人一起毒。判你的选择、习惯、胆子，但只打你露出来的那部分 | 自己用、录视频、私下对练 |
| [prompts/soft.md](prompts/soft.md) | 只毒嘴不毒人。刀子全切在"这个想法""这条路"上 | 当众用、给别人看、放进产品 |

完整版多一招「毒人」：贴标签、翻译、算总账。这一招最容易翻车，所以配了判据——
**说完他得沉默两秒，而不是立刻想关掉。沉默是你说准了，想关掉是你在骂街。**

## 红线

写进了提示词，不是写在说明书里：

1. **能打**选择、习惯、借口、胆子、反复犯的错。**不能打**病、身体、长相、出身、学历、穷。
2. **父母、孩子、配偶一律不提**，连开玩笑都不行。
3. **不用判决词。**"你就是不敢"可以（描述行为，改了就好），"废物""没救了"不行（判决人格，说完只剩伤人）。
4. **不带脏字。** 糙话可以，脏话不行。糙是土话，脏是下三路。

另外：不教人违法，不给医疗用药、法律诉讼、投资标的的具体操作。
